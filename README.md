First Java CRUD Application

Overview

This project is a simple Java CRUD application built with Spring Boot and Vaadin. It demonstrates basic student or customer record management.

Features

* Create new records
* View existing records
* Update records
* Delete records

Technologies Used

* Java
* Spring Boot
* Vaadin
* Maven

How to Run

1. Install a compatible Java JDK.
2. Open the project in IntelliJ IDEA.
3. Reload the Maven project.
4. Run the main Spring Boot application class.
5. Open the local URL shown in the application console.

Collaboration

This project was developed as part of a Java CRUD assignment to practise Git, GitHub, commits, branches, and pull requests.
